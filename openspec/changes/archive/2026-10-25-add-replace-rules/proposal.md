## Why

PRD（`docs/产品需求-第一版-2026-10-18.md`）2026-10-25 把「替换净化规则」从 P1 升到 P0，开发顺序排在第 6 步。

很多网站在正文里夹广告文字，比如「请记住本站域名」「最新章节请到某某网阅读」。书源规则里的 `##正则##替换` 只能由书源作者写，用户改不了。Legado 用户靠另一套「替换净化规则」自己去掉这些文字：规则存在 app 里，和书源无关，可以导入别人整理好的规则，也可以看到一句广告就自己加一条。现在 app 没有这个功能，每章都会读到这些文字。

## What Changes

- **规则的格式**：兼容 Legado 导出的替换规则 JSON（单个对象或数组），字段：
  - 名称、分组
  - 替换规则（正则或普通文本）和替换为
  - 是否正则
  - 作用范围、排除范围（书名或书源地址）
  - 作用于正文、作用于章节名
  - 启用
  - 超时时间
  - 顺序
- **管理页面**：设置页加一项「替换净化规则」，进入规则列表：
  - 列表按顺序显示每条规则的名称，可以逐条启用、停用。
  - 从文件、网址、粘贴文本导入，导入前显示新增、更新、跳过各几条。同一个规则 id 再次导入时更新。
  - 新建和编辑：名称、替换规则、替换为、是否正则、作用范围、排除范围、作用于正文、作用于章节名。正则无法编译时不能保存。
  - 删除，导出全部规则到剪贴板。
- **在阅读页生效**：
  - 打开一章时，正文和章节名先按启用的规则依次替换，再分段排版。
  - 正则按 Java 语法执行，和书源里的净化正则同一套实现。
  - 正文缓存里保存的仍是原文：改了规则不用清缓存，之后打开的章节就按新规则显示。
- **超时**：一条正则规则执行超过它的超时时间（默认 3 秒）时，系统中止它，跳过这条，把它停用，并在阅读页提示。这和 Legado 的做法一致，避免每打开一章都卡几秒。
- **不做**：
  - 每本书单独开关替换净化（Legado 阅读菜单里的「替换净化」）。
  - 在阅读页选中文字直接新建规则。
  - 目录列表里的章节名替换：只替换阅读页显示的章节名。
  - 规则分组的筛选和管理：只保存分组字段，导出时原样带出。
  - 拖动排序：按规则的顺序字段排列，新建的排在最后。
  - Legado 2.x（阅读 2.0）的旧规则格式。

## Capabilities

### New Capabilities

- `replace-rules`：替换净化规则的格式、导入、管理（列表、启用停用、新建编辑、删除、导出），以及规则怎样作用在一章上（作用范围、顺序、正则语义、无效规则、超时停用）。

### Modified Capabilities

- `reader`：新增「替换净化」：阅读页显示的正文和章节名先经过替换净化，正文缓存保存原文，超时停用规则时提示。
- `settings`：修改「设置页入口」，设置页多一项「替换净化规则」。
- `app-storage`：修改「落盘的数据」，替换规则（导入时的原始内容和启用状态）也落盘；清除正文缓存不影响替换规则。

## Impact

- **代码**：
  - `packages/rule_engine`：
    - 解析 Legado 替换规则 JSON，和解析书源的写法一样，返回规则和跳过的项。
    - 执行一条规则的函数和 worker 任务，复用 `SourceRegex` 和 `replaceAllJava`，所以正则能被超时中止。
  - `app/lib/storage/database.dart`：新增 `replace_rules` 表，schemaVersion 从 1 升到 2，加迁移。
  - `app/lib/online/`：
    - 新增替换规则仓库（启动时载入，写数据库后更新内存）。
    - 新增规则列表页和编辑页。
    - 导入时的取文本（文件、网址、粘贴）从书源列表页抽出来，两个页面共用。
    - `OnlineContentSource` 实现净化：按作用范围挑规则，普通文本在主 isolate 替换，正则交给 worker，超时时停用规则。
  - `app/lib/library/content_source.dart`：`BookContentSource` 新增净化方法，阅读页通过它调用，不直接引用 `rule_engine`。
  - `app/lib/reader/reader_page.dart`：取到正文后先净化再排版，有规则被停用时提示。
  - `app/lib/settings/settings_page.dart`：加入口。
- **依赖**：无新增。
- **测试**：
  - rule_engine：解析和执行规则的单元测试，包括正则超时被中止。
  - app：数据库迁移、仓库、净化、列表页和编辑页、阅读页的测试。
  - `integration_test/app_flow_test.dart` 补一段：导入一条规则，打开章节看到广告文字被去掉。
- **文档**：PRD 4.5 节的状态、README。
