## Why

PRD（`docs/产品需求-第一版-2026-10-18.md`）4.7 节把「设置页」和「关于页与免责声明」定为 P0，开发顺序排在第三步。原来和它们排在一起的「备份与恢复」已经在 2026-10-23 降到 P2，这次不做。现在 app 里没有设置入口：

- 正文缓存只会越来越多。只有把书移出书架时才会删掉，用户看不到占了多少空间，也没法清理。
- 没有地方显示版本号。app 不上架应用市场，用户只能拿版本号去和 GitHub Releases 对比，判断要不要更新。
- 约束 2 要求写明「软件不提供内容」的免责声明，现在 app 和 README 里都没有。仓库里也还没有 GPL-3.0 的 LICENSE 文件。

## What Changes

- **设置页**：书架顶栏新增「设置」按钮，进入设置页。设置页有两项：
  - 正文缓存：显示已缓存的章节数和大小，可以清除
  - 关于
- **清除正文缓存**：
  - 清除前需要确认。确认后删除所有书的正文缓存，并回收数据库文件占的磁盘空间。
  - 书籍信息、目录、阅读进度、书源、设置、书源级状态和 Cookie 都不动。
  - 之后打开清掉的章节会重新请求网络。
- **关于页**：
  - 显示 app 名称、版本号、开源协议（GPL-3.0）、源代码地址（可以复制）、免责声明。
  - 有一个入口打开第三方开源许可列表，用 Flutter 自带的许可页。
- **仓库**：根目录补上 GPL-3.0 的 `LICENSE`，README 补上免责声明。
- **不做**：
  - 备份与恢复（P2）。
  - 单本书的缓存管理、清除书源级状态或 Cookie、自动清理策略。
  - 把阅读设置搬进设置页：阅读设置仍在阅读页的菜单里。
  - 检查更新。

## Capabilities

### New Capabilities
- `settings`：设置页的入口和内容，正文缓存的大小显示和清除操作，关于页（版本、协议、源代码地址、免责声明、第三方许可）。

### Modified Capabilities
- `app-storage`：新增「清除正文缓存」要求，规定清除时删除哪些数据、哪些数据必须保留。并列的已有要求是「移出书架时清理」。

## Impact

- **代码**：
  - 新增 `app/lib/settings/`（设置页、关于页、缓存统计与清除的 provider）。
  - `storage/database.dart` 新增两个方法：统计正文缓存、清除正文缓存。表结构不变。
  - `bookshelf/bookshelf_page.dart` 的顶栏加一个按钮。
  - 这些代码都不引用 `rule_engine`，符合模块边界测试。
- **依赖**：新增 `package_info_plus`，用来读取版本号，理由见 design.md。
- **测试**：
  - 数据库层：统计和清除的单元测试。
  - 设置页、关于页：widget 测试。
  - `integration_test/app_flow_test.dart`：补一段「清除缓存后重新请求正文」。
- **文档**：仓库根目录的 `LICENSE`，README（免责声明、目录说明），PRD 4.7 节的状态。
