## Why

2026-11-03 用户导入 yckceo 书源合集 1329（320 个书源）后搜索，失败 140 个。逐个排查后，大部分是网站本身的问题：连接被关、TLS 握手失败、网站改版后书源的正则匹配不到。用户需要一个办法批量找出这些不能用的书源，再停用或删掉，而不是每次搜索都看到一长串失败。

官方 Legado、legado-E、legado-with-MD3 都有「校验书源」。用户 2026-11-03 决定：做法和 Legado 一样，校验结果写进书源的分组和注释。PRD 4.1 节把「书源校验」列为 P1，还没有开始做。

## What Changes

做法照 legado-E `CheckSourceService.kt`、`CheckSource.kt`、`BookSource.kt`（和官方 Legado 3.25 相同）：

- 多选书源后，选择栏的「更多」菜单里新增「校验」（「导出」也移进这个菜单，选择栏标题「已选 N 个」才放得下）。开始前弹出对话框，可以改关键词，默认「我的」；书源自己的 `ruleSearch.checkKeyWord` 可用时优先用它。
- 每个书源依次检查：搜索 → 第一个搜索结果的详情 → 目录 → 第一章正文；文件类书源查到详情为止。每个书源最多 180 秒，同时校验 16 个。
- 每个书源开始校验时，先去掉上次校验标上的分组（名字里带「失效」的，以及下面列出的全部分组）和注释里以 `// Error: ` 开头的段落；校验失败时按原因加上分组：
  - 没有搜索地址：「搜索链接规则为空」
  - 搜索返回 0 本：「搜索失效」
  - 目录为空：「搜索目录失效」；正文为空：「搜索正文失效」
  - 超过 180 秒：「校验超时」
  - 书源 JS 出错、用到不支持的 JS 用法或宿主 API：「js失效」
  - 其它错误（网络、规则取不到值、需要 WebView 等）：「网站失效」
  
  并且在注释最前面写上 `// Error: 原因`。通过的书源只去掉旧标记。改动写回书源的 JSON，导出时带着。
- 校验在后台进行，书源列表上方显示进度（已完成 / 总数），可以停止；离开书源页面不中断。
- 书源列表的筛选框除了名字和地址，也匹配分组和注释（Legado 的搜索框也是这四项）。校验结束时有失效的书源、并且筛选框是空的，自动填上「失效」，提示「发现有失效书源，已为您自动筛选」。失效分组也出现在分组筛选里。用户再用现有的全选、批量停用或删除处理。
- **不做**：
  - 发现页的校验（我们还没有发现页）、legado-E 额外的「域名失效」检查。
  - 校验设置（超时、检查哪几步）：固定为 Legado 的默认值。
  - 校验过程中在每个书源下面滚动显示调试信息（Legado 的 `Debug` 消息），只显示整体进度。
  - 自动停用或删除失效的书源。

## Capabilities

### New Capabilities

- `source-check`：书源校验：发起、关键词、检查步骤、超时、标记的分组和注释、进度和停止。

### Modified Capabilities

- `source-management`：「书源列表」的筛选框匹配分组和注释，校验后自动筛选失效书源。

## Impact

- **app/lib/online/**：
  - 新增 `source_check.dart`：校验控制器（16 个并发、单个书源 180 秒、进度、停止），以及给书源 JSON 加减失效分组和错误注释的函数。
  - `source_repository.dart`：新增「更新一个书源的 JSON」，保留位置和启用状态。
  - `source_list_page.dart`：选择栏加「更多」菜单（校验、导出），关键词对话框，进度和停止，筛选范围扩大，自动筛选。
  - `source_engine.dart`：`bookInfo`、`content` 和 `chapterList` 一样，可以按批量任务经限流器提交。
- **app/lib/storage/database.dart**：新增「更新书源 JSON」。不改表结构。
- **rule_engine**：`RuleException` 新增「目录为空」「正文为空」两个消息常量，链路用它们抛错，校验据此区分「搜索目录失效」「搜索正文失效」。
- **app/lib/ui/icons.dart**：新增 `ellipsisVertical` 图标；**app/lib/ui/widgets.dart**：导入用的文字输入框移过来改成公共的 `showInputDialog`（加了初始值），导入和校验共用。
- **测试**：控制器、标记函数、列表页的单元测试和 widget 测试；Android 模拟器上用合集 1329 实际校验一遍。
