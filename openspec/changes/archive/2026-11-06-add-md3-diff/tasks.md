- [x] 1.1 `tool/md3_diff/debug_result.dart`：MD3 调试日志解析成结构化结果（D4）。验证：用实际抓到的日志做单元测试，覆盖完整流程、出错、跳过详情、多行正文。

  结果（2026-11-05）：试跑和第一次全量时发现几处 MD3 日志和书的最终值不一样，按 MD3 的代码还原（设计 D4 的补充）：详情是每条规则的值、搜索记的是第 0 项、目录的「首章信息」在倒序和去重之前、封面是原始值。
- [x] 1.2 `tool/md3_diff/compare.dart`：两边结果的对比、分类和报告（D4、D5）。验证：单元测试覆盖 md3-diff「对比和分类」「报告」的场景。

  结果（2026-11-05）：`md3_diff_test.dart` 12 个（解析 5、对比和分类 7）；比较时去掉全部空白，地址里每次都变的查询参数值不算不同。
- [x] 1.3 `tool/md3_diff.dart`：连接 MD3、导入书源、按书源两边同时跑、写报告（D1、D2、D3）。验证：先跑 10 个书源检查报告。

  结果（2026-11-05）：MD3 的 WebSocket 在 1123 端口（HTTP 在 1122）。后来加了 `--resume`（读入已有报告接着跑）和 `--batch`（每次最多 N 个），开发机内存不足时长时间的后台任务会被停掉，改成在前台分批跑。
