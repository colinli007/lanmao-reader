## MODIFIED Requirements

### Requirement: 设置页入口
底部 Tab 的「我的」SHALL 是设置页，包含「替换净化规则」「书源日志」「正文缓存」和「关于」四项。点「替换净化规则」进入 replace-rules 的规则列表，点「书源日志」进入 source-management 的书源日志页。正文缓存在每次切到「我的」时重新统计。

#### Scenario: 从书架进入设置
- **WHEN** 用户在书架点底部的「我的」
- **THEN** 打开设置页，能看到「替换净化规则」「书源日志」「正文缓存」和「关于」

#### Scenario: 进入替换净化规则
- **WHEN** 用户在设置页点「替换净化规则」
- **THEN** 打开规则列表

#### Scenario: 切回来时重新统计
- **WHEN** 用户在「我的」看到缓存了 0 章，去读了 2 章后再切到「我的」
- **THEN** 「正文缓存」显示 2 章
