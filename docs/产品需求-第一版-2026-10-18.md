# 产品需求：第一版

日期：2026-10-18
依据：`idea/docs/小说阅读app/` 下的两份调研和选型文档，`docs/技术选型与验证-2026-09-28.md`，以及已经归档的 add-blocking-bridge、add-rule-engine、add-js-runtime、add-app-shell 四个 change。

这份文档定第一版要做什么、做到什么程度算完成。每项功能的详细行为写在 `openspec/specs/` 里，由各个 change 补充；这里只定范围和验收标准。第一版的功能全部完成后，统一做真机测试，然后发布。

## 一、产品定位

一个开源、完全免费的小说阅读器，兼容 Legado（开源阅读 3.0）书源。用户自己导入书源，app 按书源规则从网站取书、在本机阅读。

- **用户**：已经在用 Legado 系书源的人，愿意自己找书源、自己装 APK 或自签 IPA。不面向大众。
- **形态**：只有社区版（带书源）。不上架任何应用市场，没有服务器，没有账号。
- **核心体验**：导入书源 → 搜书 → 加书架 → 读得舒服，书源兼容做到 Legado 的水平，阅读排版不输 Legado。

## 二、约束

这些是前提，不随版本变化：

1. **完全免费**：app 内没有广告、内购；仓库不开赞助，不运营任何收益渠道。
2. **不提供内容**：仓库和安装包里不预置任何书源、站点名或书源订阅地址；不建官方书源仓库、群或频道。README 写明免责声明。
3. **没有账号和服务器**：不做注册、登录、云同步。所有数据只存在本机，换设备靠用户自己导出导入（见「备份与恢复」，P2）。
4. **不做书源登录**：书源里的 `loginUrl`、`loginUi` 登录流程不做，需要登录的书源按「不支持」报错。书源 JS 里读写登录头、登录信息的 API 照常可用（已实现）。
5. **开源协议**：GPL-3.0。

## 五、明确不做（第一版）

- 账号、登录、云同步、任何服务器。
- 书源登录流程（`loginUrl`、`loginUi`）。
- 预置书源、书源推荐、书源社区。
- 广告、内购、打赏、赞助。
- 上架版（不带书源的版本）、本地书。
- Windows、Linux、32 位 ARM。
- 漫画、音频、视频类书源。

## 六、验收标准

第一版完成的标准：上面所有 P0 做完，并且满足下面这些条件。数字是建议值，真机测试时再校准一次。

**功能**
- 每个 P0 功能都有对应的规格（`openspec/specs/`），规格里的场景都有自动化测试。
- 端到端走查（`app/integration_test/real_sources_test.dart`）在 Android、iOS、macOS 上都通过：3 个 A 类、3 个 C 类书源走完搜索、加书架、读两章、重启后继续、刷新书架。
- 走查和冒烟里失败的书源，逐个确认是网站的问题，不是引擎的问题。

**性能**（Android 中端真机）
- 冷启动到书架可操作：2 秒以内。
- 打开已缓存的章节：300 毫秒以内。
- 分页翻页不掉帧（60fps）。
- 2000 章的目录打开：1 秒以内。
- 随机 200 个书源搜一次：60 秒以内结束（现在约 150 秒）。

**体积与稳定性**
- Android 单个 ABI 的 APK：20MB 以内。
- 连续阅读 1 小时（自动翻页或脚本翻页），不崩溃，内存不持续增长。
- 书源出错（规则错误、JS 死循环、网络超时）只影响这个书源，不卡界面，不崩溃。

## 七、开发顺序

按依赖和风险排，每一步是一个 change：

1. ~~**Android 工程**~~：已完成（2026-10-18，change add-android）。app 加 Android 平台，模拟器上跑通现有全部功能和走查。
2. ~~**分页排版与翻页**~~：已完成（2026-10-19，change add-paged-reader）。分页排版、四种翻页方式、点击区域翻页、阅读主题跟随系统。
3. ~~**设置页、关于页**~~：已完成（2026-10-23，change add-settings）。
4. **搜索提速**：缩短搜索的超时、慢书源后排等，目标见验收标准。worker 数不能再加（上限 6，见选型文档）。
5. **P1 功能**，按需要挑：书架换源、缓存全本、发现页、WebView 书源、阅读的其余设置项、书签、替换规则、书源分组和校验。P1 之后再看 P2（备份与恢复）。
6. **真机测试与发布**：三个平台的真机测试，按验收标准逐条过，打包发布。
